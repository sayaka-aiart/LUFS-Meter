LUFS Meter — BOOTH配布版
プラグイン @VERSION@ / AI連携 1.0.0

OBSの「マイク・BGM・ゲーム音」と「配信全体」の音量を見比べるメーターです。
AIとの連携で、計測値を読みながらOBSの音量・フィルターを調整できます。

────────────────────────
1. ZIPの中身
────────────────────────
obs-lufs-meter.dll … OBSプラグイン本体
説明書.txt … この説明書
API/ … AIが数値を読むAPI、OBS操作API、MCPサーバー、APIの使い方
MCP設定/ … Codex用TOMLと、mcpServers形式のJSON設定ひな形

プラグインのソースコードやビルド用SDKは含みません。
APIフォルダーのスクリプトはAI連携を動かすための実行ファイルです。

────────────────────────
2. インストールする
────────────────────────
対応：Windows x64、OBS Studio 32系、モノラル／ステレオ。
メーターだけ使う場合、PythonやAIアプリは不要です。

① ZIPをすべて展開します。ZIP内から直接実行しないでください。
   AI連携も使う場合は、移動しない場所へフォルダーごと保存します。
   例：C:/LUFS-Meter/
② OBSを終了します。
③ obs-lufs-meter.dll を、OBSの obs-plugins/64bit/ へコピーします。
   通常：C:/Program Files/obs-studio/obs-plugins/64bit/
   更新の場合は同名DLLを置き換えます。必要なら以前のDLLを別の場所へ保管してください。
④ OBSを起動し、メニュー「ドック → LUFS Meter」を開きます。

APIとMCP設定はOBSのプラグインフォルダーへコピーする必要はありません。
削除するときはOBSを終了し、このDLLを取り除きます。

────────────────────────
3. メーターの基本操作
────────────────────────
・右上の歯車：表示項目、LUFS目標値、測定時間、縦／横、ソースを設定します。
・歯車の左のリセット：LUFSの測定履歴とTrue Peak MAXをクリアします。
・LUFS：音の平均的な大きさ。0に近いほど大きく、−16は−20より大きい値です。
・3秒平均：話している最中の声とBGM・ゲーム音を比較するときに使います。
・全体平均：リセット後からの配信全体を確認するときに使います。
・True Peak／MAX：ピークと計測中の最大ピーク。平均音量とは別の指標です。

共通LUFS目標の初期値は−14。3 LU手前から黄色、超えると赤です。
True Peakの黄色開始値は独立して設定できます（初期値−6 dBTP）。
LUFSのみ／True Peakのみ／両方表示を選べます。
配信マスターは、配信に選択されたOBS音声トラックの実際のミックスを測ります。
配信サービス側の音量補正や、視聴者の再生音量は含みません。

────────────────────────
4. AI連携の準備
────────────────────────
必要なもの：
・同じWindows PCのローカルファイルとMCP／コマンドを使えるAIアプリ
・Python 3.10以降（追加のPythonパッケージは不要）
・PowerShell 7以降（Windows標準のPowerShell 5.1とは別です）

① OBSのLUFS Meterで、歯車 → 外部連携 →「JSON出力」をオンにします。
②「パスをコピー」で readings.json の保存先をコピーして控えます。
③ AIに調整させるマイク・BGM・ゲーム音を、歯車 → ソースで表示対象にします。
④ OBSの「ツール → WebSocketサーバー設定」を開き、サーバーと認証を有効にします。
   接続先の通常値：ws://127.0.0.1:4455
⑤ WebSocketのパスワードを OBS_WEBSOCKET_PASSWORD ユーザー環境変数に登録します。
   パスワードをチャットや配布設定ファイルへ貼り付ける必要はありません。
   PowerShell 7.1以降で、次を実行すると伏せ字で入力できます。

   $obsPassword = Read-Host 'OBS WebSocketのパスワード' -MaskInput
   [Environment]::SetEnvironmentVariable('OBS_WEBSOCKET_PASSWORD', $obsPassword, 'User')
   $obsPassword = $null

   登録後はAIアプリを完全終了して起動し直します。
   環境変数が反映されない場合はWindowsへサインインし直してください。
   数値を読むだけなら、WebSocketとパスワードの設定は不要です。

ブラウザーで会話するだけのAIには、PC内のファイルやOBSへ接続する機能がありません。
ローカルMCPまたはコマンド実行を利用できる環境で使用してください。

────────────────────────
6. 接続後にAIへ渡す指示（配信音量調整）
────────────────────────
マイクを前に出し、BGM・ゲーム音を控えめにする例です。
最初は配信・録画を開始する前に、いつもの音源と話し方で調整してください。

----- ここからコピー -----
LUFS Meterを使い、OBSの配信音量を実際に調整してください。
API/API.mdに従い、MCPの測定・OBS操作ツールを使ってください。
MCPを利用できない場合は同梱APIをコマンドから使ってください。

【目標】
・マイクは発話中の3秒平均（Short-term）で−17〜−16 LUFSを目安にし、声を前に出す。
・BGMとゲーム音は小さめにして、声がはっきり聞こえるバランスを優先する。
・配信マスターの全体平均（Integrated）は−14 LUFS以下。
  −14は上限なので、届かせるために全体を持ち上げない。
・代表的な発話＋BGM＋ゲーム音の区間では、マスターの3秒平均も−14 LUFS以下を目安に確認する。
・変更後のTrue Peak MAXは−1 dBTP以下を目安にする。
・マイク、BGM、ゲーム音を同じLUFSに揃えない。効果音で声が隠れないようにする。
・ゲーム内の会話やムービーも聞かせたいので、通常のプレイ音とは分けて確認する。

【進め方】
1. meter_readとobs_inspectで現状を取得し、対象のOBSとソースUUIDを照合する。
   マイク・BGM・ゲーム音の役割を特定する。ゲーム音に含まれるBGMを二重計上しない。
2. 計測リセット後、「これから30秒、いつもの声と少し大きい声で話してください。
   BGMとゲーム音も普段どおり流してください」と案内してからmeter_sampleで記録する。
   無言を含む全体平均だけでマイクが小さいと判断しない。
   発話中の3秒平均でマイク−BGM、マイク−ゲーム音の差をLUで比較する。
3. 設定変更前に必ずバックアップを保存する。
   MCPでは変更ごとに自動保存されるバックアップのパスを記録する。
   コマンドでは-Applyと毎回新しい-BackupPathを使う。
4. 音量・ゲインは1〜2 dBずつ変更し、必要なコンプレッサー・リミッターも調整する。
   現在のフィルターと設定項目を確認し、OBSから変更後の値を読み直して確認する。
   APIのvolume_dbはOBSフェーダー値であり、目標LUFSをそのまま指定する項目ではない。
   無音・ミュート・準備中・古いJSONを根拠にゲインを上げない。
5. 変更後はmeter_resetでLUFS履歴とTrue Peak MAXを消し、同じ条件で30秒再計測する。
   マスターが−14 LUFSを超えたら、まずBGM・ゲーム音を下げて声を保つ。
   必要ならマイクの大声も抑える。悪化した変更はobs_restoreで逆順に戻す。
   瞬間的な声の変化を追い続けず、普通の配信で安定する設定にする。
6. 最後に、変更点、前後のマイク・BGM・ゲーム音・マスターのLUFS、
   True Peak MAX、声との音量差、バックアップの場所を簡潔に報告する。

この依頼には、上記範囲の設定変更・再計測・必要な復元を含みます。
手順の説明だけで終わらず、接続できる範囲で実行してください。
音量差だけで聞き取りやすさを断定せず、必要なら短い録音や私の聞こえ方も確認してください。
----- ここまでコピー -----

計測中は実際に声と音源を流してください。AIは話していない声の音量を測れません。
音質や歪み、EQまで調整したい場合は比較できる録音も用意してください。
MCP経由の変更ではバックアップが %LOCALAPPDATA%/LUFS-Meter/backups に作成されます。

────────────────────────
7. 困ったとき
────────────────────────
・メーターが出ない：DLLの場所、OBS 32系／Windows x64を確認し、OBSを再起動。
・JSONがない／古い：OBSを起動し、JSON出力をオン。コピーしたパスと表示ソースを確認。
・MCPが起動しない：Pythonの実行パス、展開先のパス、AIアプリの再起動を確認。
・OBSの設定が取得できない：PowerShell 7、WebSocketの有効化、ポート、パスワード環境変数を確認。
・リセット直後に数値がない：3秒平均には約3秒の音声が必要です。
・変更を戻したい：AIへ「今回のバックアップから変更を逆順に復元して」と依頼。
・ソース名が重複：AIに名前ではなくUUIDを指定させてください。
