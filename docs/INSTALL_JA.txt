LUFS Meter @VERSION@ / Windows x64 / OBS Studio 32

【導入方法】
1. OBSを終了します。
2. obs-lufs-meter.dll を次のフォルダーへコピーします。
   C:\Program Files\obs-studio\obs-plugins\64bit\
   ※別の場所にOBSを入れている場合は、その中の obs-plugins\64bit\ です。
3. OBSを起動し、「ドック」→「LUFS Meter」を開きます。

右上の歯車でソース・目標値・測定時間・縦横表示を変更できます。
表示項目のチェックで「LUFSのみ」「LUFS＋True Peak」「True Peakのみ」を選べます。
「True Peak 黄色」で黄色になる数値を変更できます（初期値−6 dBTP）。0 dBTPを超えると赤です。
MAXは計測開始後の最大True Peakです。歯車の左のリセットボタンで消去します。
初期値は3秒平均、目標 -14 LUFSです。
歯車 → 外部連携 → JSON出力で、Codexなどから測定値を読み出せます。
連携スクリプトと手順はリポジトリの docs/EXTERNAL_CONTROL.md にあります。
更新はOBSを終了してDLLを上書き、削除はOBSを終了してDLLを削除します。
